# 📊 AnalystAI – AI Powered Business Intelligence Platform

## 🚀 Overview
AnalystAI is an end-to-end data analytics web application built using Streamlit.  
It allows users to upload datasets, analyze data, visualize KPIs, and generate AI-driven business insights.

---

## 🔥 Features
- 📁 Upload CSV datasets
- 📊 Data profiling & summary statistics
- 📈 Interactive dashboards (Plotly)
- 🏢 Business KPI analysis
- 🤖 AI-generated insights (automated)
- 📥 Download reports (CSV & Excel)

---

## 🛠️ Tech Stack
- Python
- Streamlit
- Pandas
- Plotly
- Excel (XlsxWriter)

---

## 📊 Key Functionalities

### 1. Data Upload
Upload any CSV dataset for analysis.

### 2. Data Profiling
- Dataset preview
- Statistical summary

### 3. Dashboard
- Sales by City
- Product Analysis
- Payment Distribution
- Sales Trends
- Branch Performance

### 4. AI Insights
- Business insights
- Recommendations
- Opportunities

### 5. Reports
- Download processed data in CSV/Excel
