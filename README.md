## 📌 Project Overview
AnalystAI is an interactive Business Intelligence (BI) dashboard built using **Streamlit**.

It allows users to upload datasets and instantly generate insights, KPIs, and visualizations. The application transforms raw data into meaningful insights to support data-driven decision making.

---

## 🎯 Key Features
- 📁 Upload any CSV dataset  
- 📊 Automatic KPI generation (Total, Average, Max, Transactions)  
- 📈 Interactive visualizations using Plotly  
- 🔍 Dynamic filtering (City-wise)  
- 📄 Reports section with download option  
- 🤖 AI-based insights (rule-based, no API required)  
- ⚡ Fast and user-friendly interface  

---

## 📊 Dashboard Capabilities

### 🔹 KPIs
- 💰 Total Sales  
- 📊 Average Sales  
- 🔥 Maximum Sale  
- 📦 Number of Transactions  

### 🔹 Charts
- 📊 Sales by City (Bar Chart)  
- 📦 Product-wise Sales (Bar Chart)  
- 💳 Payment Distribution (Pie Chart)  
- 📈 Sales Trend Over Time (Line Chart)  

---

## 🤖 AI Insights
The application generates smart insights such as:
- Total revenue analysis  
- Average transaction value  
- Top-performing city  
- Best-selling product category  
- Most used payment method  
- Sales trend (increasing or decreasing)  

> Note: Insights are generated using rule-based logic (no external API required).
